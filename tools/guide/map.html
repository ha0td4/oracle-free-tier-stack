01Stack layers

Seven layers, outside in. Each talks only to its neighbour, so if one is exposed the layers behind it stay protected.

EntryCloudflare Free

  • DNS and SSL for the root domain (blog, unchanged) and the subdomains.
  • Access asks for a login (an emailed code, or a Pocket ID passkey after F2) before any subdomain opens.
  • WAF rate-limits /webhook; can geo-block.

Tunnelcloudflared

  • Tunnel the VM connects out to Cloudflare, so no port needs opening. It reaches only the edge (apps) and ops (admin tools) networks.

Appsedge network

  • n8n workflows, webhooks, cron. Data in SQLite.
  • OmniRoute AI gateway: many providers behind one OpenAI-compatible endpoint, with automatic fallback.
  • Hermes Agent 24/7 agent: the team uses it over Discord, Telegram runs alongside for personal use (one session per person); web dashboard is admin-only.
  • Pocket ID shared passkey login (OIDC) for Cloudflare Access, the Hermes dashboard, Grafana and Open WebUI.
  • Open WebUI chat page (yours, and members' once you open it to a team): models from OmniRoute, Hermes as the model hermes-agent, web search through SearXNG, n8n workflows as tools (MCP).

Agent toolsbackend network

  • SearXNG private search engine returning JSON to n8n; Hermes uses it as its built-in web search.
  • Crawl4AI turns web pages into clean markdown; has an MCP endpoint. Every request needs its bearer token.

Datadata network · optional

  • Postgres and Valkey only in the full tier. On a network with no Internet; only internal apps can reach them.

Monitoringops network · the observe Compose project · the hub on its own VM, always on

  • Grafana Alloy the agent on this VM: host metrics, container metrics and logs, the journal and the service checks, pushed to the monitoring hub over the VCN.
  • blackbox makes the service checks (HTTP, keyword, TCP) Alloy asks for, by name on the app networks.
  • socket-proxy read-only Docker API; Alloy goes through it.
  • Homer static admin launcher at dash.: links to every admin tool, no data of its own.
  • Prometheus on the monitoring hub, its own small VM (the free 1 GB E2.1.Micro) with systemd services and no Docker: keeps the metrics the hosts push, 90 days.
  • Loki on the hub: keeps the container logs and the journal, 90 days.
  • Tempo optional on the hub (deploy-hub.sh --tempo): keeps the traces apps send over OTLP, 30 days. Off by default: no app sends traces yet.
  • Grafana on the hub: the Hosts, Containers, Logs and Services dashboards at monitor., through the hub's own tunnel (oracle-observe).
  • node_exporter on the hub: the hub's own host metrics, next to the ones the hosts push.
  • ops network keeps Homer away from Hermes; a host firewall rule stops every container, Hermes included, from reaching the hub's logs and metrics.

HostOracle Linux 10 · SELinux · firewalld

  • Tailscale your private path for SSH and admin.
  • CrowdSec blocks bad IPs at the firewall using community blocklists.
  • restic encrypted backup at 03:30 to Oracle Object Storage plus a copy at R2 or B2.
  • Swap 4 GB, log rotation, automatic security updates (dnf-automatic). SELinux stays Enforcing; firewalld trusts the Tailscale interface.
  • 4K kernel pages are required: a 64K kernel breaks Valkey and Chromium. The setup script checks first.
